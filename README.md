# Calculadora de Médias de notas.

Este código em Python calcula a média de duas notas informadas pelo usuário e exibe o resultado. Em seguida, verifica a média: 7,0 ou mais = aprovado; abaixo de 7,0 = reprovado.

***

# Tecnologias utilizadas.

**Python 3.13.2** — linguagem utilizada para desenvolver o programa.

**Funções** — utilizadas para calcular a média das notas.

**Entrada e saída de dados** — *input()* e *print()* para interação com o usuário.

**Estruturas condicionais** — *if/else* para determinar o status do aluno.

***

# Como Instalar/Executar.

Instale o **Python 3.13.2** no computador.

Salve o código em um arquivo com a extensão *.py*, por exemplo: *calculadora_media.py*.

Abra o terminal na pasta onde o arquivo foi salvo.

Execute o programa com:

*python calculadora_media.py*

Digite as duas notas quando solicitado e o programa exibirá a média e o status do aluno.

**Exemplo de execução**

**=== Sistema de Notas do Aluno ===**

**Digite a primeira nota: 8**

**Digite a segunda nota: 7**

**A média final é: 7.50**

**Status: APROVADO!**
